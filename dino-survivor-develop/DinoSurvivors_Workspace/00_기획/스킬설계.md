# 공룡 뱀서라이크 — 스킬 설계 문서 v0.2
### (깃털 다트 / 새끼 낳기 / 알 폭탄 / 무리 사냥 / 음파 공격 / 침 뱉기 / 지진)

> 이 문서는 클로드 코드에게 구현을 맡기기 위한 **설계 스펙**입니다. 데이터 구조(Resource/JSON 등)나 노드 구조 같은 코드 아키텍처는 다루지 않고, "게임적으로 무엇이 일어나야 하는가"에 집중했습니다. 

---

## 0. 공통 규칙 (스킬 시스템 전반에 적용)

이 세 스킬뿐 아니라 게임 전체 스킬 시스템에 해당하는 공통 룰입니다. 클로드 코드가 스킬을 하나 구현할 때마다 참고할 기준선이 되니 문서 맨 위에 둡니다.

- **레벨 범위**: 모든 스킬은 Lv1~Lv5. 5레벨이 만렙.
- **레벨업 패턴(전 스킬 공통)**:
  - **Lv2, Lv4**: 수치만 상승(데미지, 쿨타임, 반경 등). 질적 변화 없음.
  - **Lv3**: 그 스킬을 상징하는 **특징적 변화**가 반드시 하나 붙음 (판정 추가, 개수 증가, 새로운 부가효과 등 — 눈에 띄는 변화).
  - **Lv5**: 진화 가능 상태가 됨. 진화 전까지는 Lv4와 동일한 성능 + 소폭 강화 정도.
- **진화(Evolution)**: 스킬이 5레벨을 찍으면 진화 가능.
  - 한 스킬이 **2개 이상의 진화 갈래**를 가질 수 있음 (선택형).
  - 진화는 단순 수치 강화가 아니라 **투사체 형태·판정 방식 자체가 바뀌는 질적 변화**여야 함.
- **합체(Fusion)**: 이미 진화한 스킬 2개가 특정 레시피로 만나면 새로운 상위 스킬로 합쳐짐.
  - 합체 스킬은 원본 두 스킬의 컨셉을 계승하되, 완전히 새로운 이름/이펙트를 가진 별도 스킬로 취급.
  - (알 폭탄 항목에 합체 예시 포함)
- **캐릭터 매칭**: 이 세 스킬은 각각 특정 캐릭터의 시작 스킬임.
  - 깃털 다트 → **미크로랍토르** (작고 재빠른, 활공하는 네 날개 육식공룡)
  - 새끼 낳기 → **마이아사우라** ("좋은 엄마 도마뱀"이라는 뜻. 실제로 집단으로 둥지를 틀고 새끼를 돌본 것으로 유명한 공룡)
  - 알 폭탄 → **오비랍토르** ("알 도둑"이라 오해받았지만, 실제로는 자기 알을 품고 지키던 좋은 부모였다는 반전이 있는 공룡)

## 1. 깃털 다트 (Feather Dart) — 미크로랍토르 시작 스킬

**컨셉**: 몸집이 작고 네 개의 날개로 활공하는 미크로랍토르가 깃털을 뽑아 던지는 초반 견제기. 가볍고 빠르지만 한 발 한 발은 약함. 캐릭터 자체가 스피드/기동형이라, 스킬도 "정직한 화력"보다는 "여러 적을 스치듯 훑는" 방향으로 성장하는 게 자연스러움.

| 항목 | 값 |
|---|---|
| 타입 | 투사체 / 단일 타겟 |
| 조준 방식 | 가장 가까운 적 자동 조준 후 직선 발사 |
| 쿨타임 | 짧음 (초반 딜링 담당) |
| 캐스트 딜레이 | 중간 (던지는 모션이 살짝 보이는 정도) |
| 판정 | 명중 시 즉시 피해, 관통 없음 (레벨업 전까지) |

### 레벨별 변화
- **Lv1**: 깃털 1발. 기본 데미지, 기본 쿨타임.
- **Lv2**: 데미지 증가 (수치만).
- **Lv3 — 특징 변화**: 관통 1회 추가. 깃털이 얇고 가벼워서 첫 적을 스치고 뒤의 적까지 닿는다는 설정. (미크로랍토르의 활공 컨셉과 자연스럽게 연결)
- **Lv4**: 쿨타임 감소(연사력 강화) + 데미지 소폭 증가 (수치만).
- **Lv5**: 진화 가능 상태. 진화 전까지는 관통 유지 + 소폭 강화만.

### 진화 (Lv5 이후 선택)
- **진화 A — 질풍깃털 (연사형)**: 양 날개에서 동시에 2발 발사 + 관통 횟수 대폭 증가 + 탄속 상승, 치명타 시 적을 살짝 밀어냄(넉백). 방향성: "빠르고 얇게 여러 마리를 긋는" 스타일로 전환. 두 날개로 나는 미크로랍토르의 정체성이 가장 잘 드러나는 진화.
- **진화 B — 가시깃털 (폭발형)**: 명중 시 그 자리에서 작은 파편 2~3개가 사방으로 튀며 소범위 추가 피해. 방향성: 관통 대신 "명중 지점 소규모 광역"으로 전환.
  - 두 진화는 상호 배타적(택1)이며, 이후 다른 스킬과의 합체 레시피 후보로 열어둘 수 있음(추후 설계).

### 연출 메모
- 발사 시: 어미 공룡이 깃털을 뽑는 짧은 모션 → 발사.
- 명중 시: 깃털이 꽂히는 느낌보다는 "스치고 지나가는" 가벼운 타격 이펙트(파티클 적고 빠르게 사라짐).
- 사운드: 휙 스치는 소리, 무겁지 않게.

## 2. 새끼 낳기 (Birth Offspring) — 마이아사우라 시작 스킬 (우선순위 x)

**컨셉**: "좋은 엄마 도마뱀"이라는 이름 그대로, 마이아사우라가 새끼공룡을 낳아 곁에서 함께 싸우게 함. 실제로 집단으로 둥지를 틀고 새끼를 돌봤다는 실존 특성이 그대로 "소환수가 어미 곁을 맴돌며 함께 싸운다"는 게임 메커니즘으로 옮겨감. 이 게임의 시그니처 소환 스킬.

| 항목 | 값 |
|---|---|
| 타입 | 소환수 (지속형) |
| 소환수 행동 | 어미와 별도로 자율 이동, 가장 가까운 적에게 근접 공격(할퀴기/물어뜯기) |
| 이탈 제한 | 어미로부터 일정 거리 이상 멀어지지 않도록 리시(leash) 범위 존재 — 범위를 벗어나면 적 추적을 멈추고 어미 쪽으로 복귀 |
| 재소환 | 새끼가 죽으면 일정 시간 후 자동 재소환 (완전히 사라지는 스킬이 아님) |

### AI 동작 개념 (구조 설계 아님, 행동 로직만)
새끼공룡의 행동 우선순위는 다음 3단계로 이해하면 됩니다.

1. **추적**: 리시 범위 안에 적이 있으면 가장 가까운 적을 향해 이동, 사거리 도달 시 근접 공격 반복.
2. **복귀**: 추적 중이던 적이 리시 범위 밖으로 나가거나, 새끼 자신이 어미로부터 리시 범위 이상 벌어지면 즉시 추적을 포기하고 어미 쪽으로 복귀.
3. **대기(배회)**: 주변에 적이 없으면 어미를 중심으로 살짝 배회 — 한 자리에 뻣뻣하게 멈춰있지 않고 자연스럽게 움직이는 정도.

이 3단계 전환에 명확한 우선순위(추적 > 복귀 > 대기)만 있으면 되고, 상태머신이든 단순 if 분기든 구현 방식은 클로드 코드 재량.

### 레벨별 변화
- **Lv1**: 새끼공룡 1마리 소환.
- **Lv2**: 개별 새끼의 공격력/체력 증가 (수치만, 마리 수 유지).
- **Lv3 — 특징 변화**: 새끼공룡 **2마리**로 증가. 이 스킬에서 가장 눈에 띄는 변화 지점.
- **Lv4**: 마리 수 유지(2마리), 리시 범위 확장 + 이동속도 강화 (수치만, 더 적극적으로 싸우는 느낌).
- **Lv5**: 마리 수 유지(2마리), 개별 공격력 대폭 강화 + 진화 가능 상태.

### 진화 (Lv5 이후 선택, 예시 2안)
- **진화 A — 육식 본능**: 새끼공룡의 공격이 확정 치명타 확률을 갖고, 적 처치 시 짧은 시간 광폭화(공속 상승). 공격적인 딜러형 소환수로 전환.
- **진화 B — 무리 본능**: 마리 수가 1마리 추가되어 3마리가 되고, 새끼들끼리 서로 가까이 뭉쳐 있을 때 소폭 데미지 버프를 공유. 마이아사우라의 "무리 육아" 컨셉이 가장 잘 드러나는 진화. 물량형 소환수로 전환.

### 연출 메모
- 소환 시: 알이 아주 살짝 형태를 갖췄다가 새끼가 톡 튀어나오는 정도의 짧은 연출 (알 폭탄과 시각적으로 헷갈리지 않게, 알 폭탄보다 훨씬 작고 귀여운 느낌).
- 새끼공룡 공격: 할퀴기(짧은 선딜, 빠른 판정) 또는 물어뜯기(살짝 더 느리지만 넉백 약간) — 랜덤 또는 레벨 구분으로 둘 다 써도 됨.

## 3. 알 폭탄 (Egg Bomb) — 오비랍토르 시작 스킬

**컨셉**: 이 게임의 대표 광역기. "알 도둑"이라는 오명과 달리 실제로는 자기 알을 품고 지키던 오비랍토르가, 그 알을 무기로 던져 착탄 지점에서 터뜨림. 방어적인 존재가 공격 수단으로 알을 쓴다는 반전이 컨셉의 핵심.

| 항목 | 값 |
|---|---|
| 타입 | 투사체 / 광역(폭발) |
| 조준 방식 | 가장 밀집된 적 근처 또는 랜덤 지점(사거리 내) — 취향껏, 밀집도 기반 추천 |
| 쿨타임 | 김 (한 방이 강한 스킬) |
| 딜레이 | 김 (포물선으로 날아가는 비행 시간 존재 → 적이 회피할 여지가 있는 스킬) |
| 판정 | 착탄 시 폭발, 폭발 범위 내 전체 피해 |

### 레벨별 변화
- **Lv1**: 기본 데미지, 기본 폭발 반경.
- **Lv2**: 데미지 증가(수치만).
- **Lv3 — 특징 변화**: 폭발 반경 증가
- **Lv4**: 데미지 증가 (수치만).
- **Lv5**: 쿨타임 소폭 감소 + 진화 가능 상태.

### 진화 (Lv5 이후 선택, 2갈래)
- **진화 A — 왕특란(대형화)**: 알 크기와 폭발 반경이 크게 커지고 데미지도 대폭 상승. 대신 쿨타임/딜레이가 더 길어짐 — "느리지만 한 방이 확실한" 방향.
- **진화 B — 알 다발**: 한 번에 여러 개의 작은 알을 부채꼴로 투척. 개별 알의 반경/데미지는 낮아지지만 커버리지와 총 데미지가 늘어나고 쿨타임도 짧아짐 — "넓고 잦은" 방향.

### 합체 스킬 예시 — 백린탄 (컨셉 샘플)
말씀하신 "왕특란(대형화) + 불길 지대 생성 스킬" 조합의 합체 스킬 예시입니다. (불길 지대 스킬 자체는 아직 미설계 상태라 여기선 합체 결과만 컨셉으로 정리했습니다.)

- **이름(가안)**: 백린란 (White Phosphorus Egg)
- **컨셉**: 왕특란급 크기의 알이 착탄과 동시에 폭발 + 그 자리에 넓은 화염 지대가 일정 시간 남아 지속 화상 피해를 줌.
- **차별점**: 기존 알 폭탄류가 "한 번의 폭발"이었다면, 백린란은 **즉발 폭발 데미지 + 지속 장판 데미지**의 이중 구조. 쿨타임은 두 원본 스킬보다 길지만, 화력 총량이 확실히 우위.
- **디버프**: 장판 안에 있는 적은 화상 스택이 쌓이는 방식으로 설계하면 다른 화염류 스킬과도 시너지 낼 수 있음(추후 다른 화염 스킬 설계 시 스택 공유 여부 결정).

### 연출 메모
- 투척 시: 포물선 궤적이 눈에 보이는 게 중요 (플레이어가 "피할 수 있다"는 긴장감).
- 착탄 시: 알 껍데기가 펑 터지는 파열 이펙트 + 짧은 스크린 셰이크(폭발감).
- 사운드: 낮고 묵직한 "펑" — 깃털 다트와 확실히 구분되는 무게감.

## 4. 추가 스킬 4종 (시작 스킬 여부 미정 — 모티브 공룡은 확정)

레벨 패턴은 위 세 스킬과 동일하게 적용: **Lv2·Lv4 수치만 / Lv3 특징 변화 / Lv5 진화 갈림(2안)**.

### 4-1. 무리 사냥 (Pack Hunt) — 벨로키랍토르

> 참고: 벨로키랍토르의 "무리 사냥"은 화석 증거보다는 대중문화(쥬라기 공원 등)에서 굳어진 이미지에 가깝습니다. 게임적 재미를 위한 설정으로 그대로 채택했습니다.

**컨셉**: 순간적으로 동료 랩터가 나타나 근처 적 무리 한 곳을 할퀴고 사라지는 버스트형 광역기. 지속 소환수인 "새끼 낳기"와 달리, 이쪽은 **한 번 치고 빠지는 히트&런** 스타일이라 역할이 겹치지 않음.

- 조준 방식: 화면 내 적이 가장 밀집된 지점(랜덤 요소 가미 가능)을 향해 동료가 순간 출현.
- 판정: 출현 지점 주변 소범위 전체 피해, 공격 직후 동료는 사라짐.
- 쿨타임/딜레이: 둘 다 짧은 편 — 자주 튀어나오는 게 컨셉의 핵심.

**레벨별 변화**
- Lv1: 동료 1마리 출현, 1회 할퀴기 후 사라짐.
- Lv2: 데미지 증가 (수치만).
- Lv3 — 특징 변화: 할퀴기 횟수 1회 증가 (랜덤위치)
- Lv4: 쿨타임 감소 (수치만).
- Lv5: 진화 가능 상태.

**진화**
- 진화 A — 비열한 협공: 할퀴기가 다단히트(3회)로 변경
