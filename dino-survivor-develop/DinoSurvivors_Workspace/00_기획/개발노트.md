- 자리표시 아트: 지형 타일 4종(잔디/흙길/모래/물·바위, 전부 다른 색 + 타일 경계선), 장식 2종(노랑/검정, 10px 크기, 대비되는 테두리) — 전부 `tile_placeholder_factory.gd`에서 색상 배열만으로 정의. 장애물/파괴 가능 오브젝트는 이번 작업 범위에서 제외(추후 별도 작업).
- 몹 스폰(`wave_manager.gd`)은 플레이어 위치 기준 반경 스폰이라 청크 시스템과 무관하게 그대로 동작 — 수정 없음.
- 연동: `scenes/main/Main.tscn`에 `ChunkContainer`(Node2D) 추가(기존 `GridBackground` 자리를 대체, Player보다 트리 순서상 앞이라 배경으로 그려짐), `scripts/systems/main.gd`에서 `ChunkManager.start(player, chunk_container)` 호출 추가, `project.godot`에 `ChunkManager` autoload 등록.
- 정리: 더 이상 안 쓰는 `scripts/debug/grid_background.gd`(+ `.uid`) 삭제, 빈 폴더 유지를 위해 `scripts/debug/.gitkeep` 추가. `README.md`/`폴더_관리_가이드.md`의 관련 설명도 갱신.

2. 개발자 메뉴(Dev Menu) 구현
- 배경: 기존에는 화면 우측 상단에 "레벨업" 버튼 하나만 있던 것을, 여러 치트 기능을 모은 메뉴로 확장. 요구사항상 "추후 삭제가 쉬울 것"이 최우선 조건이라, 관련 코드를 최대한 한 곳에 격리하는 방향으로 설계.
- 구조: `autoload/dev_tools.gd`(버튼 하나짜리 기존 파일)를 삭제하고 `scripts/debug/dev_menu.gd`(신규)로 대체. `~`(Tilde) 키 또는 우측 상단 버튼으로 메뉴를 열고 닫으며, 여는 동안 기존 일시정지 UI들(`pause_menu_ui.gd` 등)과 동일한 컨벤션(`get_tree().paused` 직접 토글 + `process_mode = PROCESS_MODE_ALWAYS`)을 그대로 사용. 메뉴 UI는 전부 코드로 동적 생성(별도 씬 없음).
- 포함 기능: 레벨업 +1(`RunState.add_experience` 재사용), 풀피 회복/즉사, 무적 토글(기존 `Player.is_invincible`이 시간제한형이라, 매 프레임 강제로 true 유지하는 방식으로 외부에서 우회 — `player.gd` 자체는 무수정), 타임스케일 조절(0.5x/1x/2x/3x, `Engine.time_scale`), 스킬 목록(스크롤 리스트)에서 스킬별 레벨 지정(`-`/`+`)·삭제 버튼.
- 유일하게 격리 밖 파일을 건드린 부분: `scripts/systems/skill_controller.gd`에 `remove_skill()`(레벨 무관 완전 제거, 인스턴스 노드 정리 포함), `dev_set_skill_level()`(정확한 레벨 지정, 0 이하면 제거) 두 함수를 추가. 둘 다 "개발자 메뉴 전용" 주석을 달아 표시해둠.
- 버그 하나 잡음: 즉사 버튼으로 사망시킨 뒤 메뉴를 닫으면 `GameOverUI`가 걸어둔 일시정지를 덮어써서 게임오버 화면 뒤에서 캐릭터가 움직이던 문제 → `dev_menu.gd`의 닫기 로직에 `RunState.is_game_over` 가드를 추가해서 해결.
- 삭제 방법(추후): `scripts/debug/` 폴더 삭제 + `project.godot`의 `DevTools=...` Autoload 한 줄 삭제 + `skill_controller.gd`의 "개발자 메뉴 전용" 표시된 두 함수 삭제, 이 세 가지만 하면 완전히 원상복구됨.

3. 지진 (신규 구현)
- 기존에는 스킬설계.md 4-4에 설계 텍스트만 있고 코드/데이터/씬이 전혀 없던 스킬이었음(모티브 캐릭터 아르헨티노사우루스도 아직 게임에 없음). 이번에 처음부터 새로 구현.
- 구조: 다른 광역기(무리 사냥/철퇴 내려찍기)와 마찬가지로 `BaseAreaEffect`를 상속하되, 판정 형태만 원형이 아닌 "회전된 직사각형"으로 바꿔야 해서 신규 클래스 `EarthquakeCrack`을 추가함 — `_strike_all_overlapping()`을 오버라이드해서 기존에 있던 회전 사각형 AOE 헬퍼 `_deal_aoe_damage_box()`(원래 물기 판정에서만 쓰이던 함수)를 그대로 재사용. 새 물리/수학 코드 없이 프레임워크 조합만으로 구현됨.
  - `EarthquakeSkill`(어디에·몇 개의 균열을 스폰할지 결정, `owner_body.facing_direction` 기준으로 캐릭터 바로 앞에서 시작해 뻗어나가도록 배치) → `EarthquakeCrack`(균열 자체, `hit_delay` 동안 흔들리다 판정 시점에 사각형 범위 전체 타격 후 페이드).
  - "살짝 흔들리다 갈라지는 전조" 연출: `BaseAreaEffect.hit_delay`(원래 무리 사냥 발톱 애니메이션과 스윙을 맞추던 용도)를 그대로 캐스트 딜레이로 사용하고, `EarthquakeCrack`에 자체 `_process()`를 추가해 `hit_delay`가 끝나기 전까지 시각 노드를 매 프레임 랜덤하게 흔들다가 판정 순간 정확히 멈추는 방식으로 구현.
- 레벨별 변화(Lv1~Lv5) 전 항목 구현 완료. 설계서상 지진은 알 폭탄/무리 사냥과 달리 레벨에 따라 범위(직사각형 크기)가 커지지 않는 스킬이라, `rect_size`는 레벨 무관 고정값으로 두고 데미지/쿨타임만 레벨별 배열로 표현:
  - Lv1: 기본 데미지, 기본 범위(260×90px).
  - Lv2 / Lv4 — 데미지 증가(수치만): `level_damage` 배열([1.0, 1.2, 1.45, 1.7, 1.85]).
  - Lv3 — 데미지 증가 + 쿨타임 감소: 알 폭탄 Lv5/깃털 다트 Lv4/침 뱉기 Lv2·4에 쓴 것과 동일한 `level_cooldown_multiplier` 배열 + `_leveled_cooldown()` 오버라이드 패턴을 재사용([1.0, 1.0, 0.85, 0.85, 0.85], Lv3부터 쿨타임 15% 감소).
  - Lv5: 진화 가능 상태(설계서 공통 규칙 "Lv4와 동일 성능 + 소폭 강화" 반영 — 쿨타임은 Lv4와 동일하게 유지, 데미지만 배열 마지막 값으로 소폭 추가 상승).
- 진화 A "대격변" 구현 완료: 1차 균열과 같은 지점에 90도 회전된 균열을 하나 더 동시에 스폰해서 십자(+)형으로 확장 — 좌표 계산 없이 `facing.angle() + PI * 0.5`로 각도만 틀어서 재사용.
- 진화 B "여진" 구현 완료: 1차 균열의 `cast_delay`가 끝난 뒤 `aftershock_delay`(0.6초)만큼 더 기다렸다가, 같은 좌표(`anchor`, 스킬 발동 시점에 한 번만 계산해 고정)에 데미지 65~70%로 약화된 2차 균열을 추가 스폰. 이미 한 번 전조가 있었으니 2차 균열의 흔들림 시간은 짧게(`AFTERSHOCK_HIT_DELAY=0.15`)만 줌.
- 아트: 전용 스프라이트가 없어서 균열 시각 효과는 Polygon2D 사각형 placeholder로 구현(무리 사냥/침 뱉기와 동일한 방식). 스프라이트가 준비되면 `EarthquakeCrack`의 `Visual` 노드를 Sprite2D로 교체하면 됨.
- 캐릭터(아르헨티노사우루스) 데이터 자체가 아직 없어서 시작 스킬로 연결하지는 않음 — 스킬은 공용 풀(SkillDatabase)에 정상적으로 노출되므로, 캐릭터 데이터가 추가되면 그쪽 `starting_skill`에 `earthquake`를 연결하기만 하면 됨.
